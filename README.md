DIGITAL MARKETING ANALYTICS DASHBOARD :-
Project Overview
This project analyzes digital marketing campaign performance across different channels, devices, customer segments, and countries using Tableau. The dashboard helps marketers track revenue, ROI, CTR, CVR, conversions, impressions, and audience engagement.

TOOLS USED:-
Tableau Public
Excel/CSV Dataset
Data Visualization
Marketing Analytics

Key Findings
Social and Search channels generated the highest revenue.
Mobile devices recorded the highest CTR.
Fashion segment achieved the highest conversions.
Social channel delivered the best ROI.

Conclusion
The dashboards provide a comprehensive view of campaign effectiveness, customer engagement, channel performance, and business growth metrics. The analysis helps marketers optimize budget allocation and improve campaign performance.
